# Aitho Desktop (beta) downloads

Installers for the Aitho Desktop app: the Aitho presenter in a native window next to your camera, kept out of
screen share where the operating system allows it. Same Aitho account, same voice commands as https://aitho.app.

**Beta:** these builds are not yet signed by Apple or Microsoft, so your computer will ask you to confirm before
opening them. Install steps: https://aitho.app/download

Questions: help@aitho.app
